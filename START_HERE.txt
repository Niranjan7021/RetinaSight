RETINASIGHT QUICK START

1) Start backend in a terminal:
   cd backend
   python -m pip install -r requirements.txt
   python app.py

2) Start frontend in another terminal:
   cd frontend
   npm install
   npm run dev

3) Open http://localhost:5173

Demo mode note: upload validation, database history and CSV report work. Disease classification is intentionally disabled until a trained/validated model is connected. Read README.md.
